# 📊 Predictive Analytics Using Historical Data

## Sales Forecasting Using Superstore Historical Data

### Objective
Build a predictive model using historical sales data to forecast future sales trends.

### Project Overview
This project analyzes historical Superstore sales data and uses machine learning to predict future sales. The workflow includes data cleaning, preprocessing, exploratory analysis, feature engineering, model training, evaluation, and future forecasting.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

### Machine Learning Model
Random Forest Regression

### Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
